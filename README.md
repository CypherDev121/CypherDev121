Développeur FiveM basé au Québec. Je construis des ressources Lua, des interfaces NUI et des bases serveur complètes — du schéma SQL au dernier détail d'un menu.

Mon terrain de prédilection : les systèmes qui restent fluides et sécurisés une fois le serveur plein, et les interfaces qu'on comprend sans explication.

## Ce que je fais

**Systèmes serveur** — logique de jeu en Lua, events validés côté serveur, persistance SQL.

**Interfaces NUI** — HUD, inventaires, menus et écrans sur mesure en HTML/CSS/JS, ou via RageUI.

**Bases FiveM** — bases RP/PvP/FreeRoam complètes : ressources, configuration, base de données, installation.

## Façon de travailler

- **Le serveur a le dernier mot.** Les events clients sont validés côté serveur ; aucune valeur sensible n'est acceptée telle quelle.
- **La performance se mesure.** Boucles à sleep dynamique, payloads courts, aucune requête SQL dans les boucles critiques.
- **L'interface s'efface.** Une NUI rapide et lisible, qui laisse le joueur dans le jeu.
